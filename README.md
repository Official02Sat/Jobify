# Jobify - Job Search Application

A responsive job search web application built with React, Vite, and Tailwind CSS.

## Features
- **Authentication**: Login with credentials and secure JWT token storage in cookies.
- **Protected Routes**: Only authenticated users can access the Home and Jobs pages.
- **Job Search & Filters**: Search jobs by role/title, filter by employment type and salary range.
- **Sticky Sidebar**: Fixed profile, filters, and salary options on desktop while scrolling job listings.
- **Fully Responsive**: Mobile-friendly navigation with responsive drawer menu.

## Tech Stack
- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM v6
- **Icons**: React Icons
- **Auth**: js-cookie

## How to Run Locally

1. Clone the repository:
```bash
git clone <your-repository-url>
cd jobify
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open `http://localhost:5173` in your browser.
